# Renderer decision

Date: 2026-10-18

- **Video renderer:** HyperFrames. It renders the animated background as a seamless loop (MP4 and WebM) with a poster fallback.
- **Remotion:** not used. designme allows one video renderer per project. The user chose HyperFrames.
- **motionmaxxing:** not used. Its measured-motion film path would be a second renderer.
- **Hairline:** not used. No interactive figure was requested.
- **Opus 5.5 video-prompt catalog:** not used. The Opus 5.5 model is the design model. The catalog is a separate prompt source.
- **UI/UX Pro Max:** requested. The site contains UI, so UI/UX artifacts are produced.

Source: the approved brief in `brief.json` and the approved design doc in `docs/plans/2026-10-18-paddlebase-registration-design.md`.
